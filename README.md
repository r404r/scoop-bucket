# r404r Scoop bucket

Scoop bucket for an **unofficial, unsigned** x64 portable build of [RNP](https://github.com/r404r/rnp) from the r404r/rnp fork. It is not an official rnpgp/rnp release.

## Install

```
scoop bucket add r404r https://github.com/r404r/scoop-bucket
scoop install r404r/rnp
```

## Notes

- The binaries are unsigned, so Windows SmartScreen may warn on first run.
- The default keyring is `%USERPROFILE%\.rnp`.
